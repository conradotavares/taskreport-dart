# TaskReport Dart

## Sobre o projeto

O TaskReport Dart é um simulador de tratamento de dados de tarefas em Dart puro.
O projeto simula o retorno de uma API por meio de uma lista de mapas,
transforma esses dados em objetos e gera relatórios com base nos status das tarefas.

## Objetivo

Praticar os principais conceitos do Módulo 01:
- lógica de programação
- linguagem Dart
- tipos de dados
- estruturas de decisão e repetição
- funções e arrow functions
- Lists, Maps e Sets
- métodos de coleção
- classes, objetos, atributos e métodos
- construtores, encapsulamento, herança e polimorfismo com @override
- GitHub, GitFlow e Kanban

## Como executar

```bash
dart run main.dart
```

## Tecnologias
